Running on the pages you visit

UOKey works by reading the page in front of you: the text of its links, buttons and fields, so that Ctrl Space can find them. Firefox only lets it do that on sites you have allowed.

What else Firefox lets it do

Read and modify bookmarks is for ;marks, which searches them. UOKey only reads them and never changes one.

Access browser tabs is for ;tabs, which searches your open tabs by title and address; for the numbered tabs ; lists, and ;d0 … ;dz, which unloads them; and for the site icons all of these show.

Storage, which Firefox does not ask about, keeps those icons, the two settings below and, until Firefox closes, whether the bar is on and the order you used your tabs in. Nothing UOKey reads is sent anywhere.

Settings

Off, nothing comes up while a command is typed: only ;help and ;; put anything up. The same switch as typing ;;hints in the bar.

;s is ;shortcut as soon as it is typed, ;h is ;help, and so on. The same switch as typing ;;fast in the bar.

;; in the bar lists both, and ;;settings opens this page.
